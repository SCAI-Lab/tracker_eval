# Third-party runtime subsets

This repository carries compact runtime subsets for reproducible research evaluation. The upstream projects remain the authoritative implementations and their notices in each implementation folder remain applicable.

- AB3DMOT: <https://github.com/xinshuoweng/AB3DMOT>
- CBMOT: <https://github.com/cogsys-tuebingen/CBMOT>
- ELPTNet: <https://github.com/jinzhengguang/ELPTNet>
- FastPoly: <https://github.com/lixiaoyu2000/FastPoly>
- GNN-PMB: <https://github.com/chisyliu/GnnPmbTracker>. Murty is built locally from the supplied C++ source.
- SimpleTrack: <https://github.com/tusen-ai/SimpleTrack>
- TrackEval: <https://github.com/JonathonLuiten/TrackEval>. Only the JRDB3DBox dataset and HOTA/CLEAR/Identity/Count runtime are retained; this checkout includes the supplied corrected 3D IoU and polygon clipping implementation.

PedRefTrack is original project code and is also available as a separate ROS2 repository: <https://github.com/Draxran/PedRefTrack>.
